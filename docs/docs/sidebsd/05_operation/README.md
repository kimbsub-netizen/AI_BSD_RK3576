# Side BSD Operation Documents

> Status: CURRENT  
> Applies to: Side BSD  
> Updated: 2026-09-13

이 폴더는 Side BSD의 운영·배포·현장 운용 문서를 관리한다.

## 현재 문서

- `Side_BSD_운영_배포_가이드.md` — 개발/측정/차량 배포 단계별 설정과 체크리스트
- `Side_BSD_보드_배포_패키지_가이드.md` — 보드 배포 패키지와 진단 절차
- `Side_BSD_사용자_안전_및_시스템_한계.md` — 사용자 안전문구 및 시스템 한계 Baseline

## 범위

- TEST / PRODUCTION 운용 절차
- 배포 전 확인 항목
- 로그/성능 모니터링 절차
- 실제 차량/보드 I/O 연동 후 운용 절차
- 차량별 캘리브레이션 기록 관리
- 장애/FAULT 운영 대응 절차

캘리브레이션 절차는 `../03_calibration/`, 검증 절차는 `../04_validation/`에서 관리한다.

공통 개발환경 또는 세 프로젝트 공통 운영 문서는 `docs/shared/`에서 관리한다.
